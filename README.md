NLP Chatbot - ElevanceSkills Internship Tasks

This repository contains all the tasks I completed during my Data Science internship at ElevanceSkills. The project is based on a fitness and first-aid chatbot I built during the training phase and each task extends it with new features.

About the Project

During training I built a basic chatbot using Python, NLTK, TensorFlow and Keras that answers questions about gym injuries, fitness and first aid. The internship tasks build on top of that chatbot by adding more advanced features like a dynamic knowledge base, image understanding, medical Q&A, sentiment analysis and multilingual support.

Tasks

Task 1 - Dynamic Knowledge Base

Extended the chatbot with ChromaDB so new knowledge can be added without retraining the model.

Task 2 - Multimodal Chatbot

Added image understanding using Google Gemini Vision so the chatbot can analyse uploaded images.

Task 3 - Medical Q&A Chatbot

Built a medical question answering system using the MedQuAD dataset with 16000+ Q&A pairs from NIH and CDC.

Task 4 - Sentiment Analysis

Integrated NLTK VADER sentiment analysis so the chatbot detects user emotions and responds appropriately.

Task 5 - Multilingual Support

Extended the chatbot to support English, Hindi, Spanish, French and German with automatic language detection.
